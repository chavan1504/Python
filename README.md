# Python

**************** BASIC COMMANDS *******************************

-print()  :  display data on the console 

-input()  :  receiving input from the users

-len()    :  get the length of a data structure

-type()   :  get the data type or variable 

-range()  :  generate sequence of numbers

-help()   :  get document for a function



****************** VARIABLE AND DATA TYPES ***************************

-int     :   convert to integer

-float   :   convert to float

-bool    :   convert to boolean

-list    :   create a list

-dict    :   create a dictionary

-tuple   :   create a tuple

-set     :   create a set

-str     :   convert to string 

************************* CONTROL STRUCTURES ***************************

-if,elif,else : conditional branching

-for loop : loop through a sequence

-while loop : loop if condition is true 

-break : exit a loop early

-continue : sking the current iteration 

-pass : null operation, do nothing

********************** FUNCTIONS *************************************

-def : define a new function 

-return : return a value from a function

-lambda : create anonymous function

****************** CLASSES AND OOP ***********************************

-class : define a new class

-self : refers to instance of the class 

-__init__() : constructor method 

****************** MODULES AND PACKAGES *****************************

-import : load an external module 

- from...import : load specific part of module

****************** EXCEPTION HANDLING *****************************

-try,except : handle exception 

-finally : execute code after try-except 

-ralse : trigger an exception 

***************** FILE HANDLING ***********************************

-open() : open a new file 

-read() : read the content of the file 

-write() : write to a file 

-close() : close an open file 

***************** DECORATORS AND GENERATORS *********************

@decorator_x : apply a decorator to a function 

-yeild : return a value from generation 

******************* LIST COMPREHENSIONS ************************

[ expression for item in list if condition ] :  create a new list by iterating and apply a condition
